Remote Gaming Architecture: Bypassing LAN Limitations

Systems & Networking
Apollo & Artemis Tailscale (Mesh VPN) ESP32 Wake-on-LAN Embedded C++

What started as a simple idea—wanting to play my desktop PC games from a beach house on my Retroid Pocket 5—turned into a deep dive into host-client streaming software. To achieve ultra-low latency without paying for cloud subscriptions or opening unsecure router ports, I built a self-hosted ecosystem. The setup uses Apollo and Artemis for native-resolution streaming, Tailscale to establish a zero-trust WireGuard mesh network, and an ESP32 microchip programmed to listen on UDP and relay Wake-on-LAN magic packets locally to my sleeping PC from anywhere in the world.

Parallel Image Filtering via Matrix Convolution

High-Performance Computing
C++ CUDA OpenMP MPI FreeImage API

Generated grayscale outputs using FreeImage across OpenMP, CUDA, and MPI by implementing a 3×3 matrix-convolution image filtering pipeline in C++. Achieved a 3.25× CPU speedup using OpenMP with "collapse" and "schedule" directives, reduced average runtime by 9.38× by mapping pixels to CUDA threads under benchmarked block sizes (128 to 1024 threads per block), and implemented an MPI version to document communication overhead trade-offs.
